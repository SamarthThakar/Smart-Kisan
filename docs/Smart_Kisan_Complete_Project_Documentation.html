Smart Kisan Project Guide Section 1 • Overview & Mission

1 Project Overview & Core Mission

Smart Kisan ("Smart Farmer") is an end-to-end, full-stack, artificial intelligence-powered agricultural advisory platform created specifically to address the structural technology divide in Indian agriculture. Over 140 million farming households in India face recurring agricultural and economic vulnerabilities due to five fundamental challenges:

1. Asymmetric Crop Health Information

Farmers often fail to diagnose fungal and bacterial leaf diseases until irreversible damage occurs. Agricultural extension officers (Krishi Vigyan Kendras) are understaffed and geographically distant from remote villages.

2. Suboptimal Crop Selection

Sowing choices are frequently based on tradition or speculative market hype rather than objective soil chemistry (Nitrogen, Phosphorus, Potassium, pH) and seasonal meteorological forecasts.

3. Market Mandi Price Exploitation

Middlemen (arhtiyas) leverage price opacity in regional Agricultural Produce Market Committees (APMCs) to purchase farmer harvests well below prevailing modal market rates.

4. Underutilization of Government Welfare

Billions of rupees allocated under PM-KISAN, PMFBY (Crop Insurance), and Kisan Credit Card (KCC) remain unclaimed because eligibility rules are buried in complex government portals.

The Smart Kisan Solution

Smart Kisan consolidates six distinct agricultural domains into a single, high-performance, mobile-first web ecosystem accessible across desktop, tablet, and smartphone browsers in the farmer's native tongue (English, Hindi, and Marathi):

  • Instant Leaf Disease Diagnosis: Point-and-shoot computer vision diagnostics delivering actionable chemical treatments, preventative measures, and KVK contact recommendations within seconds.
  • Agronomic Crop Advisor: Scientific crop recommendations matching exact soil nutrient parameters (NPK, pH) and micro-climate inputs with regional soil presets.
  • Real-time Mandi Intelligence: Transparent pricing across major Indian markets with automatic "Best Mandi" profit optimization highlights.
  • Precision Meteorological Alerts: 7-day hyperlocal forecast paired with rule-based operational advisories (foliar spray timing, rain shelter alerts).
  • National Welfare Directory: Searchable repository of subsidies, loans, and insurance schemes with direct application pathways.
  • Conversational Krishi Mitra AI: 24/7 multilingual agronomic intelligence grounded in ICAR research through Retrieval-Augmented Generation (RAG).

Request Lifecycle & Execution Flow

  1. Client Dispatch: The user interacts with the UI. The frontend service module (frontend/src/services/api.js) intercepts the request and automatically attaches the JWT bearer token from localStorage if present.
  2. Reverse Proxy / CORS: In development, the Vite server proxies API calls from port 5173 to port 8000. In production, FastAPI's CORS middleware ensures only authorized domains can access backend endpoints.
  3. Security & Rate Limiting: SlowAPI inspects the client IP address. High-compute endpoints (such as image disease prediction) are capped at 10 requests per minute to prevent resource exhaustion.
  4. Authentication Resolution: get_current_user verifies token signatures using HS256. If no token is provided, requests still succeed gracefully via the built-in Guest Mode fallback.
  5. Business Logic & Inference: The router triggers the corresponding service. ML models are loaded lazily into memory on the first request to eliminate cold-start server lag.
  6. Database Transaction: Queries, caches, and records are committed via SQLAlchemy sessions and returned through Pydantic response models.

Smart Kisan Project Guide Section 5 • Feature Deep-Dive

5 In-Depth Feature Breakdown

Smart Kisan is built around 7 core modules, each engineered with strict validation, real-time feedback, and offline fallback capability:

1. Leaf Disease Doctor (/disease)

Allows farmers to upload or snap a photo of an infected leaf. The platform executes an AI visual diagnostic and returns a tailored disease report.

  • Input: Image file (JPEG, PNG, WebP) up to 10MB via file picker or webcam.
  • File Validation: Validates MIME headers and inspects raw magic bytes (\xFF\xD8\xFF for JPEG, \x89PNG for PNG, RIFF for WebP) to prevent malicious executable injection.
  • Inference Engine: Resizes image to 224x224 RGB, applies ImageNet normalization, and runs EfficientNetB3 inference across 38+ plant pathology classes.
  • Output: Top-3 predicted diseases with confidence scores, severity rating (None, Medium, High), chemical treatments, cultural preventative actions, and a Krishi Vigyan Kendra (KVK) advisory notice.
  • Built-in Samples: Includes instant 1-click test leaves (Tomato Early Blight, Healthy Potato, Corn Rust) for seamless demonstrations.

2. Crop Advisor (/crop)

Predicts the top 5 most profitable and biologically suitable crops based on soil chemistry and regional weather parameters.

  • Inputs: Nitrogen (0-200 kg/ha), Phosphorus (0-200 kg/ha), Potassium (0-200 kg/ha), pH (0-14), Temperature (°C), Humidity (%), and Annual Rainfall (mm).
  • Regional Soil Presets: Quick-fill buttons for Black Cotton Soil (High K, medium N/P), Alluvial Soil (Balanced NPK), and Red Laterite (Acidic, low N/P).
  • Inference Engine: Standardizes input features via StandardScaler and evaluates them using a Random Forest Classifier trained on ICAR multi-crop benchmarks.
  • Output: Ranked list of 5 crops with suitability percentages, water requirements (Low/Medium/High), optimal growing season (Kharif, Rabi, Zaid), and current market demand.

3. Weather Advisory & Alert Engine (/)

Integrates precision meteorological data with agronomic heuristic rules to safeguard crops against adverse weather events.

  • Data Provider: Open-Meteo REST API. Completely free, high-uptime, requiring zero API keys.
  • Parameters: 7-day temperature range (min/max), relative humidity, precipitation probability, wind speed, and reference evapotranspiration (ET0).
  • Agronomic Rule Engine (weather_rules.py):
    • Foliar Spray Advisory: Flags high winds (>15 km/h) or impending rain (>40%) to warn against wasted pesticide application.
    • Crop Inundation Warning: Alerts farmers when rainfall exceeds 50mm within 24 hours.
    • Frost Protection Alert: Warns northern farmers when night temperatures dip below 4°C.
  • Intelligent Cache: Caches weather responses in the database for 6 hours per coordinate pair to eliminate redundant network traffic.

4. Live Mandi Market Prices (/market)

Empowers farmers to negotiate fair prices by providing real-time commodity pricing across Agricultural Produce Market Committees (APMCs).

  • Data Source: data.gov.in official Open Government Data (OGD) platform with automated fallback to realistic price simulations.
  • Commodity Scope: 23 primary Indian crops including Rice, Wheat, Cotton, Soybean, Onion, Tomato, Mustard, and Turmeric.
  • Market Intelligence:
    • Displays Minimum, Maximum, and Modal (prevailing) prices per quintal (100 kg).
    • "Best Mandi" Badge: Highlights the local market offering the highest modal payout.
    • Recharts Interactive Graph: Renders visual price comparisons across state mandis.

5. Government Welfare Schemes Directory (/schemes)

Centralizes welfare programs, subsidies, and credit schemes from the Ministry of Agriculture and Farmers Welfare.

  • Cataloged Schemes: PM-KISAN (£6,000 direct income support), PMFBY (Pradhan Mantri Fasal Bima Yojana - crop insurance), KCC (Kisan Credit Card at 4% subsidized interest), e-NAM (National Agriculture Market), and AIF (Agriculture Infrastructure Fund).
  • Filtering Dimensions: Scheme type (Subsidy, Insurance, Credit, Organic), state applicability, and target farmer category (Marginal, Small, Medium).
  • Direct Action: Full eligibility breakdowns, documentation requirements, and direct external links to official government application portals.

6. Krishi Mitra Multilingual AI Specialist (/chat)

A 24/7 agricultural domain chatbot powered by Google Gemini 1.5 Flash grounded with ChromaDB vector search.

  • Multilingual Engine: Native conversational understanding and generation in English, हिंदी (Hindi), and मराठी (Marathi).
  • RAG Grounding: Vector database contains verified agronomic advisories. Restricts the model from inventing unverified chemical dosages or false pricing.
  • Conversation Memory: Retains dialogue history for multi-turn conversational follow-ups.

7. Farmer Profile & Consolidated History (/profile)

A centralized dashboard for personal farm metrics, past diagnostic reports, and application-wide preferences.

  • Farm Demographics: Landholding acreage, primary cultivated crops, state/district, and soil classification.
  • Audit Logs: Unified chronological timeline of previous leaf disease scans (with preview thumbnails) and crop recommendation runs.
  • Instant Localization: Allows switching the active UI language across all pages with a single click.

Smart Kisan Project Guide Section 8 • Machine Learning Pipeline

8 Machine Learning & AI Pipeline Deep Dive

The intelligence layer of Smart Kisan is split into three dedicated engines designed for fast inference and resilience under offline or uninstalled conditions:

1. Plant Pathology Vision: EfficientNetB3 (disease_model.py)

EfficientNetB3 scales depth, width, and resolution using a compound coefficient. It balances lightweight edge inference with high diagnostic accuracy on complex leaf textures.

Python Inference Pipeline
# 1. Lazy Loading (Loads into RAM only upon the first diagnostic request)
model = tf.keras.models.load_model("models/disease_model.keras")

# 2. Image Preprocessing
image = Image.open(BytesIO(image_bytes)).convert("RGB").resize((224, 224))
img_array = np.array(image, dtype=np.float32)
img_array = tf.keras.applications.efficientnet.preprocess_input(img_array)
img_array = np.expand_dims(img_array, axis=0)  # Shape: [1, 224, 224, 3]

# 3. Softmax Classification across 38+ plant pathology classes
raw_probs = model.predict(img_array, verbose=0)[0]
top3_idx = np.argsort(raw_probs)[-3:][::-1]
predictions = [{"disease": class_names[i], "confidence": float(raw_probs[i])} for i in top3_idx]

Fail-Safe Fallback: If TensorFlow binary weights are missing during local development, the system automatically falls back to high-fidelity mock diagnostic data (e.g. Tomato Late Blight at 87.3% confidence) to ensure the UI remains fully functional.

2. Agronomic Crop Recommendation: Random Forest (crop_model.py)

Trained on the ICAR Multi-Crop dataset across 2,200 soil-climate observations covering 22 distinct crops. Uses 100 decision trees to avoid overfitting on single soil parameters.

Crop Predictor Pipeline
# Feature vector order: [N, P, K, pH, temperature, humidity, rainfall]
raw_features = np.array([[n, p, k, ph, temp, humidity, rainfall]], dtype=np.float32)

# StandardScaler Normalization
scaled_features = scaler.transform(raw_features)

# Class Probability Estimation
probabilities = model.predict_proba(scaled_features)[0]
top5_indices = np.argsort(probabilities)[-5:][::-1]
recommendations = [
    {"crop": label_encoder.inverse_transform([idx])[0], "suitability": round(probabilities[idx] * 100, 1)}
    for idx in top5_indices
]

3. Conversational RAG Engine: Gemini 1.5 Flash + ChromaDB (rag_engine.py)

Combines sub-second LLM generation with domain-verified agricultural publications stored in a local ChromaDB vector collection:

  • Vector Storage: Indexed agricultural chunks from ICAR, extension bulletins, and government schemes using cosine similarity distance thresholds (distance < 0.7).
  • System Prompt Constraints: Enforces domain isolation — declines medical, political, or off-topic questions; speaks in the farmer's dialect; explicitly recommends consulting local Krishi Vigyan Kendras for severe outbreaks.
  • Conversation Memory: Contextually threads the last 3 conversational turns to maintain dialogue coherence during follow-up questions.
Smart Kisan Project Guide Section 9 • Frontend & Design System

9 Frontend Architecture & Design System

The frontend is built with React 19 and Vite. It avoids third-party CSS frameworks like Tailwind or Bootstrap in favor of a bespoke 58KB Vanilla CSS design system (index.css) optimized for smooth rendering on low-cost Android devices.

Harmonious Design Tokens

Built with agricultural tones: Deep Forest Green (#14532d), Leaf Emerald (#22c55e), Golden Harvest Amber (#d97706), and clean neutral grays for sunlight readability.

Adaptive Navigation

Desktop users get a permanent 7-item sidebar. Mobile devices switch to a fixed bottom 5-tab bar and a top bar with breadcrumb tracking.

Global Authentication & The "Guest Mode" Pattern

To prevent user friction in rural communities, Smart Kisan provides a Guest Mode managed by AuthContext.jsx:

  • On load, the app checks localStorage for an existing JWT token.
  • If present, it validates the token via GET /api/v1/auth/me and hydrates the farmer's profile.
  • If absent, it automatically logs in a default guest user ("Kisan Mitra (Demo)"). Every feature remains accessible, ensuring zero onboarding friction for new visitors.

Internationalization (i18n.js)

All UI strings across all 7 views are stored directly in frontend/src/i18n.js. Farmers can toggle between English, Hindi, and Marathi in real time without refreshing the page or making network requests.

Smart Kisan Project Guide Section 10 • Security & Setup

10 Security, Reliability & Quality Assurance

Cryptographic Token Security

Authentication utilizes HS256 JWT tokens with a 24-hour expiration window. Passwords are salted and hashed using bcrypt via passlib.

Magic-Byte Upload Validation

Prevents file extension spoofing by inspecting raw binary headers (JPEG, PNG, WebP) and enforcing a 10MB file size ceiling.

IP-Based Rate Limiting

SlowAPI enforces 10 requests per minute on deep learning inference routes, preventing denial-of-service from malicious actors.

Safe ORM Parameterization

SQLAlchemy 2.0 uses parameterized SQL queries, completely eliminating SQL injection risks across all endpoints.
